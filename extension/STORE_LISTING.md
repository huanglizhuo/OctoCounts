## Store Name

OctoCounts – GitHub SLOC & Code Statistics

## Short Description (manifest `description`)

See per-language SLOC, file counts, code lines, comments, and blanks directly on public GitHub repositories.

## Tagline

The SLOC panel GitHub forgot.

Use this on screenshots, the website, or inside the detailed description. Do not put it in the store name.

## Detailed Description

Get actual lines of code for any public GitHub repository without cloning.

OctoCounts is a SLOC counter for GitHub: it adds a code statistics panel directly to repository pages, with no command-line tools like tokei or cloc needed.

What you get:

• Lines of code per language
• File counts per language
• Total, code, comment, and blank lines

Use it to:

• Check a repo's size before cloning
• Gauge project complexity
• Compare forks or alternatives
• Browse open-source projects without leaving GitHub

OctoCounts runs on public GitHub repositories and shows results right in the GitHub UI.

### Privacy

OctoCounts does not collect, store, or sell your personal data.
