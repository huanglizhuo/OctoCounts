# OctoCounts search visibility review

On November 21, 2026, HTTP checks covered all 35 URLs in the static sitemap, 20 evenly spaced comparison entries and 20 evenly spaced report entries. All 75 returned HTML with a title and no page-level noindex directive. Advertised Markdown alternates in the sample returned Markdown. All 35 static pages had a self-referencing canonical and one H1. An unknown path returned 404.
