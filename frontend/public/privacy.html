Privacy Policy

Data Collection

OctoCounts does not collect personal data. No accounts, no cookies, no tracking identifiers. You can use the tool anonymously.

Analytics

We use Cloudflare Web Analytics, a privacy-first analytics service. It collects aggregated, non-personal data (page views, referrers, browser types) without cookies or fingerprinting. Cloudflare Web Analytics does not track individual users across sessions.

Repository Host APIs

When you analyze a repository, OctoCounts sends the repository URL to the public GitHub API to resolve the branch, tag, or commit SHA. OctoCounts does not store GitHub credentials and only accesses public repository metadata.

Data Storage

SLOC reports are cached by repository owner, name, commit SHA, and tokei version. This cache contains only public repository data (language statistics) and no personal information. Cached reports can be accessed by anyone who knows the repository URL and commit.

Source Code

OctoCounts is open source. You can inspect the full codebase at github.com/huanglizhuo/OctoCount.
