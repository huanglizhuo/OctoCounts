Bug Reports & Feature Requests

OctoCounts is maintained by one developer. Open an issue on GitHub; it is the fastest way to get a response.

github.com/huanglizhuo/OctoCounts/issues

What to Include

  • The GitHub repository URL you were analyzing
  • Expected vs. actual behavior
  • Browser and OS (for frontend issues)
  • Screenshots if applicable
  • For a wrong line count: the commit SHA, the date and the counting rules printed on the report page

Before reporting a line count that looks wrong

OctoCounts counts the source archive at one commit with tokei, under rules the report page prints: the commit SHA, the engine version and the excluded directories. A local tool on a different checkout, at a different version, or with different exclusions can report different totals. By default documentation, test and generated directories are excluded. The counting methodology explains each rule, and the largest codebases guide shows how a count is cited with its commit and date.
