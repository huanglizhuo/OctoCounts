# SEO / GEO 全站检查与修复 · 2026-10-31

本轮覆盖抓取与索引、动态报告与集合页、canonical、结构化数据、HTML / Markdown 一致性、中英文文档、AI 入口、分享元信息、客户端水合及资源预算。已有预渲染、robots、分片 sitemap、可引用报告和测量体系继续复用。本文件记录代码修复与验证，不代表已经部署、收录或提升排名。

## 发现与修复

| 问题 | 修复后的行为 | 验证 |
|---|---|---|
| 交互分析会清除 `analysis/reportId`，非公开规范规则的结果随后被绑定到普通报告 URL；该 URL 的 SSR 是另一组计数 | 非规范结果复用既有快照链接：地址栏、canonical、Dataset 和 Markdown 指向同一 `reportId`，并保持 noindex。重新使用公开规范规则时恢复普通 URL 与 index | 浏览器覆盖自定义分析、换仓库、重算，以及切回规范规则 |
| 客户端无条件设置 index，可能覆盖缺失报告的 noindex，也未遵守已有五文件收录门槛 | 加载过程中保留服务器索引决策；真实报告使用前后端共享门槛。临时故障仍可重试，不主动改成 noindex；旧 SSR 报告省略规则时保留其公共 URL | 404/503、4/5 文件、default/tree/commit 路由回归 |
| 浏览器加载后把仓库专属 OG/Twitter 图覆盖为首页图；从首页运行分析时没有 Markdown alternate | 正常报告使用仓库图，快照使用通用图；创建或更新 Markdown alternate，随报告身份一起变化 | 初始报告、换仓库、快照与规范结果切换回归 |
| 报告与比较 Markdown 请求在上游故障时实际返回 HTML | 明确返回 text/markdown、503、no-store 和 Retry-After | `.md` 与 `?format=md` 故障回归；HTML 仍返回 HTML |
| 集合超过末页仍返回 200 空白样板，产生无限可抓取的低价值分页 | `/recent`、`/popular`、`/hall-of-monoliths` 的空末页返回 404 和返回首页链接。真实空首页仍为 200，上游故障仍为 503 | 三种集合、空首页和故障回归 |
| FAQ 推荐可变 canonical 作为固定引用；tokei-online 过度保证同提交/引擎必然同数 | HTML、Markdown 和现有 FAQ schema 统一说明固定 reportId、完整 SHA、引擎、有效规则，以及缓存清理与导出要求 | 文档跨格式回归、产品事实检查 |
| 部分方法论文档可见日期、Markdown 与 schema 日期不同；llms 存在过时研究与引用示例 | 修复日期一致性，更新研究范围和引用说明，删除证据不足的历史数字示例；只为实际改文的 FAQ、tokei-online 和 llms 更新 manifest 日期 | 全部 EN/ZH 指南日期一致性、sitemap/manifest 同步测试 |

公开规范规则排除 tests/docs/generated；它与交互表单允许选择的规则并不相同。本轮没有修改计数算法、用户选项或后端数据，只使不同计数对应正确的报告身份。

## 线上基线

修改期间只读抽样首页、中文首页、文档索引、方法论、关于、研究、统计、报告及比较页：均正常响应，具有单一 H1、自指 canonical 和结构化数据。robots 允许搜索及 AI 检索；sitemap 索引和 llms.txt 可读取；旧 facebook/react 报告跳转到 react/react；随机不存在 URL 返回真正的 404。

这只是公开 HTTP 抽查，不能证明真实爬虫 IP 通过 WAF，也不能证明所有长尾 URL 已收录。

## 发布与效果验证

验证结果：TypeScript、Vite 与中英文首页预渲染构建通过；SEO 回归 127/127；单元测试 63/63；Chromium 浏览器回归 61/61（含报告元数据、规则切换、中英文及响应式/视觉检查）；产品事实、CSP、资源预算与 diff 空白检查通过。新 SEO 测试已接入 `npm test`。浏览器测试使用受控 API fixtures，部分非关键请求因本地后端未启动而记录连接失败，不等于生产端到端验证。

本轮仅需发布前端。发布后复查上述路由、文档及自定义/规范报告切换；用预览环境模拟上游故障，确认 Markdown 503 和空分页 404。无需中断生产 API 来测试。

继续使用 [现有测量规范](seo-geo-measurement.md) 与 [索引操作说明](seo-index-runbook.md)：对比等长 28 天的 GSC 页面组点击/展现、Bing AI Performance 引用与被引用页面、AI 来源访问和分析完成事件。引用次数不等于访问次数；不能从代码改动推断排名因果关系。未取得 GSC/Bing 私有数据，也未测真实用户 Core Web Vitals，本轮不填写虚构分数。
