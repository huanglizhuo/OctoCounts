## 未做的事及原因

- **按 GSC 数据收紧报告页收录门槛**：需要先看 Search Console 中 `sitemap-reports-1` 的收录率，没有数据时不批量 noindex。
- **lockfile 计入 generated 排除**：会改变全部计数，需要升级计数策略版本并更新方法论，属于产品决策。
- **报告页新增独特数据（同语言规模百分位、增长、GitHub 元数据）**：新功能，单独设计。
- **compare 页 LCP（实验室 3.6 s）**：先用 Cloudflare Web Analytics 的真实用户 CWV 判断是否需要改渲染方式。
- **AlternativeTo 分类、Stack Overflow / Reddit 回答、Bing Webmaster 后台、GitHub Marketplace 发布**：需要维护者账号登录。

## 发布顺序与部署后检查

后端先于 Pages 发布（`languageCount` 与新引用措辞来自后端；前端在旧后端下会回退到 `languages.length`）。

1. 打版本 tag 构建镜像，按 sloc-infra 流程在两台节点部署并 `make drift`。
2. 推送 `main` 触发 Cloudflare Pages。
3. 线上检查：`/stats` 冷缓存不再 503；报告页 title 为 `… lines of code | OctoCounts`、引用含 "Canonical public options"、描述语言数为完整数量；`/docs` 200 且各指南面包屑可达；`/sitemap-compare.xml` 带 lastmod；`llms.txt` / `llms-full.txt` 内容更新。
4. 执行 IndexNow `--core` 推送核心页。
